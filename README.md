## Summary

These scripts and the associated dataset (see *Associated dataset download*) contains example passive cavitation detection (PCD) recordings that accompany the associated publication. The included scripts can be used to quantify cavitation dose from these data. The study tested whether cavitation generated by ultrasound-activated phase-change contrast agents (PCCAs) improves topical antibiotic therapy of skin wounds infected with methicillin-resistant *Staphylococcus aureus* (MRSA) in mice.

**Experimental context.** Mouse wounds were inoculated with MRSA on day 0. On days 2, 3, and 4 after infection, each mouse was given a topical combination of gentamicin (an antibiotic) and palmitoleic acid two times per day. Following one of the two daily applications, PCCAs with an octafluoropropane (OFP) core were applied topically and the wound was exposed to ultrasound (1.1 MHz center frequency, 9.09% duty cycle) at a peak negative pressure (PNP) of either 700 or 1700 kPa. Each daily ultrasound session consisted of five separate 60-second exposures ("treatments" 1–5). While the ultrasound was on, a passive cavitation detector (a receive-only transducer that "listens" to sound emitted by oscillating or collapsing bubbles) captured acoustic emissions from the wound, with a recording saved every 15 seconds; in the example dataset these recordings are stored in the `expData` variable. Before each day's ultrasound session, a baseline signal was recorded from the wound with PBS only (no acoustically responsive PCCAs); in the example dataset these recordings are stored in the `PBSData` variable.

The processing scripts for this example dataset (see *Code/Software*) show how we calculated the "cavitation dose" for each animal presented in the paper. Each recording was filtered and split into harmonic and broadband components, and each component was integrated over frequency. The corresponding baseline (PBS) value was then subtracted, and the resulting net values were integrated over the exposure time and summed across the five daily treatments to give a daily cavitation dose for each animal. The daily doses from days 2–4 were summed to give the total cavitation dose, which was compared against the bacterial load in the wound measured on day 5. The correlation between wound bacterial burden and cavitation dose is presented in the associated publication (Figure 6). For more information about the filtering, please see the associated publication.

**What is included.** To keep the download small, this is an *example* subset rather than the complete study dataset. It contains every recording from all three treatment days for two animals, one from each pressure group:

| Animal ID | PNP group | Treatment days included |
|---|---|---|
| 2 | 1700 kPa | Day 2, Day 3, Day 4 |
| 16 | 700 kPa | Day 2, Day 3, Day 4 |

Together with the MATLAB analysis scripts (see *Code/Software*), these files let a user reproduce our cavitation-dose calculation step by step and check their output against the values reported for animals 2 and 16 in the associated publication (Figure 6).

## Description of the data and file structure

### Background: how the cavitation signals were acquired

During each exposure, the signal from the receive transducer (Y-107, Sonic Concepts; 100 kHz–15 MHz) was digitized with a 14-bit analog-to-digital converter (PDA14, Signatec) sampling at 100 MHz. Each acquisition contained 200 digitized RF signals (A-lines) recorded from 70 to 120 µs, which a custom LabVIEW program saved to a desktop computer as a TDMS file. One TDMS file was saved every 15 s during each 60-second exposure. For this repository, the TDMS files were read into MATLAB, and the voltage and time data were extracted and combined into a single .mat file for each day. No filtering or other signal processing was applied to the voltage data; all spectral analysis is performed by the provided scripts.

### Data Files

| File | Contents |
|---|---|
| `D2exampleData.mat` | All PCD recordings from day 2 post-infection for animals 2 and 16 |
| `D3exampleData.mat` | All PCD recordings from day 3 post-infection for animals 2 and 16 |
| `D4exampleData.mat` | All PCD recordings from day 4 post-infection for animals 2 and 16 |

The "D" in each file name stands for "day post-infection." All three files share an identical structure.

### MATLAB structures

Each .mat file contains two variables:

| Variable | Size | Contents |
|---|---|---|
| `expData` | 1 × 50 structure array | Treatment recordings: 2 animals × 5 treatments per day × 5 recordings per treatment (at 0, 15, 30, 45, and 60 s) |
| `PBSData` | 1 × 2 structure array | Baseline recordings: 2 animals × 1 baseline recording acquired before that day's treatments. Matched to `expData` by `animalnum`. |

Each element of a structure array is one PCD recording (i.e., one original TDMS file). Each element has the following fields (`PBSData` does not contain `treatmentnum` or `timepoint`):

| Field | MATLAB class / size | Units | Description |
|---|---|---|---|
| `filename` | char | – | Name of the original TDMS file the recording was extracted from. |
| `pressure` | double, scalar | kPa | Peak negative pressure (PNP) setting for the treatment. Categorical: `700` or `1700`. |
| `animalnum` | double, scalar | – | Animal identification number. In this dataset: `2` (1700 kPa group) or `16` (700 kPa group). These IDs match the animal numbers used in the associated publication. |
| `treatmentnum` | double, scalar | – | Which of the five 60-second ultrasound exposures given that day the recording belongs to. Integer from `1` to `5`, in the order delivered. |
| `timepoint` | double, scalar | s | Time within the 60-second exposure at which the recording was saved, measured from the start of that exposure. Values: `0`, `15`, `30`, `45`, or `60`. |
| `voltData` | double | V | Raw PCD voltage. Each of the 200 rows is one sequentially acquired RF capture (A-line); each of the columns is one digitized sample within that capture. The receive chain was not calibrated, so these voltages cannot be converted to acoustic pressure. They are intended for relative amplitude comparisons only. |
| `time` | double | µs | Time vector for the samples in `voltData`, shared by all 200 rows (column *j* of `voltData` was sampled at `time(j)`). The sampling interval is `time(2) - time(1)`. |

**Relationships between fields.** A single recording is uniquely identified by the combination of the day file + variable (`expData` or `PBSData`) + `animalnum` + `treatmentnum` + `timepoint`. To plot a single RF capture in MATLAB, use `plot(expData(k).time, expData(k).voltData(r,:))`, where `k` is the recording index (1–50) and `r` is the A-line number (1–200).

**Missing data.** There are no missing values or placeholder codes in these files; every expected recording for both animals on all three days is present. (When applied to the full study dataset, `cavitationAnalysis_Step2` fills any missing 0 s or 60 s recording with the mean of the same timepoint from that day's other treatments and lists these in its `imputeLog` output.)

### Abbreviations

| Abbreviation | Meaning |
|---|---|
| A-line | One RF capture (one row of `voltData`) |
| AUC | Area under the curve. In `pcdFFT4`, the integral of a band-limited amplitude spectrum over frequency; in `cavitationAnalysis_Step2`, the integral of that value over exposure time |
| D2, D3, D4 | Day 2, 3, and 4 post-infection (the treatment days) |
| FFT | Fast Fourier transform, used to convert each RF capture into a frequency spectrum |
| MRSA | Methicillin-resistant *Staphylococcus aureus* |
| OFP | Octafluoropropane (perfluoropropane, C3F8), the core of the PCCAs |
| PBS | Phosphate-buffered saline; used for the baseline (no-PCCA) recordings |
| PCCA | Phase-change contrast agent; lipid-coated droplets that vaporize into microbubbles when exposed to ultrasound of sufficient pressure |
| PCD | Passive cavitation detection / detector |
| PNP | Peak negative pressure of the ultrasound wave |
| RF | Radiofrequency; the raw, unprocessed voltage signal recorded by the transducer |
| SD | Standard deviation |
| TDMS | Technical Data Management Streaming, the National Instruments file format written by LabVIEW |

### Key terms for users new to the field

- **Cavitation** is the formation, oscillation, and/or collapse of gas bubbles driven by an ultrasound field. The bubbles re-radiate sound, which the PCD records.
- **Harmonic emissions** are narrow-band peaks at integer multiples of the 1.1 MHz driving frequency. They arise mainly from bubbles oscillating stably and are commonly used as an indicator of *stable cavitation*. In this analysis, the 3rd, 4th, and 5th harmonics (3.3, 4.4, and 5.5 MHz) are used.
- **Broadband emissions** are elevated signal spread across the spectrum between the harmonic peaks, produced mainly by bubbles collapsing violently. They are commonly used as an indicator of *inertial cavitation*. In this analysis, broadband emissions are measured between 3.3 and 5.5 MHz, excluding ±110 kHz around each harmonic.
- **Total cavitation** is all emissions (harmonic + broadband) in the 3.3–5.5 MHz band.
- **Net** values have the background signal subtracted: the mean value from that animal's PBS baseline recording (acquired each day before PCCAs were administered) is subtracted from each treatment value, and negative results are set to zero.
- **Cavitation dose** is the net harmonic, broadband, or total cavitation AUC integrated over exposure time and summed over the five treatments and three treatment days for a given animal.

## Code/Software

**Software used:** MATLAB R2023a or later (required for `tiledlayout`/`nexttile`) with the Signal Processing Toolbox (required for `cheb2ord`, `cheby2`, `zp2sos`, and `filtfilt`). The scripts were written and tested in MATLAB. No other toolboxes or third-party functions are required. The original data were acquired with a custom LabVIEW program.

### Scripts

| Script | Purpose |
|---|---|
| `pcdFFT4.m` | Helper function called by Step 1. For each A-line it removes the DC offset, computes a zero-padded single-sided amplitude spectrum (32,768-point FFT), and isolates three components with zero-phase Chebyshev type II band-pass filters (60 dB stopband attenuation): (1) **harmonic**: 3rd–5th harmonics, each with a ±55 kHz passband; (2) **broadband**: 3.3–5.5 MHz with ±110 kHz around each harmonic removed; (3) **total**: 3.3–5.5 MHz. Each component's spectrum is integrated over frequency (trapezoidal rule) to give one AUC value per A-line. |
| `cavitationAnalysis_Step1.m` | Processes one treatment day. Runs `pcdFFT4` on every `PBSData` and `expData` recording, excludes A-lines in which the transmit pulse was off (amplitude at the spectral peak < 10% of the recording maximum), subtracts each animal's mean PBS AUC from every treatment A-line to obtain net values (negative values set to 0), and saves `exportCavData` and `PBSData` to `<dayfile>_cavDataExport.mat`. |
| `cavitationAnalysis_Step2.m` | Loads the three per-day export files. For each animal, treatment, and timepoint it calculates the mean and SD of the net AUC across the 200 A-lines, integrates these over the exposure (0–60 s, trapezoidal rule) to give a per-treatment dose, and sums the doses over the five treatments and three days. SDs are propagated in quadrature at each step. It plots net cavitation vs. time for every treatment and day and prints the summary table `T_summary`. |

### Workflow to reproduce the example results

1. **Set up the code.** Download `cavitationAnalysis_Step1.m`, `cavitationAnalysis_Step2.m`, and `pcdFFT4.m` from the GitHub repository and add their folder to your MATLAB path.
2. **Download the data.** Save `D2exampleData.mat`, `D3exampleData.mat`, and `D4exampleData.mat` from this Dryad record into a single folder.
3. **Run Step 1 once per treatment day.** Run `cavitationAnalysis_Step1`. When prompted, select one of the day files (e.g., `D2exampleData.mat`), then choose a folder to save the results. The script saves `D2exampleData_cavDataExport.mat`. Repeat for the remaining two day files so that you end up with three export files (D2, D3, and D4).
4. **Run Step 2.** Run `cavitationAnalysis_Step2`. When prompted, select the D2, D3, and D4 export files in that order.
5. **Check the results.** Compare the MATLAB figures generated by Step 2 (one figure per animal per day) to the supplemental figures for animals 2 and 16 in the associated publication. The `T_summary` table printed in the Command Window should match the values below.

| Column | Description |
|---|---|
| `PressureAnimal` | Group label in the form `"PNP_animalID"` (e.g., `"1700_2"` = 1700 kPa group, animal 2) |
| `harmonicAUCnet_TotalAUC` | Net harmonic (stable) cavitation dose summed over all treatments and days |
| `harmonicAUCnet_TotalAUC_SD` | Propagated SD of the harmonic dose, derived from the variability across the 200 A-lines in each recording |
| `broadbandnet_TotalAUC` | Net broadband (inertial) cavitation dose |
| `broadbandnet_TotalAUC_SD` | Propagated SD of the broadband dose |
| `totalcavnet_TotalAUC` | Net total cavitation dose (all emissions in the 3.3–5.5 MHz band) |
| `totalcavnet_TotalAUC_SD` | Propagated SD of the total cavitation dose |

Cavitation dose values are calculated from linear amplitude spectra of uncalibrated voltage data, so they are reported in arbitrary units (a.u.). They are best interpreted as relative measures for comparing animals and pressure groups within this study, not as absolute acoustic quantities.
